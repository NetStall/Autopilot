# job-autopilot

Personal tool for a structured job search in Germany: fetch vacancies, rank direct employers above agencies, draft tailored cover letters with the Claude API, review and approve them, send, and track responses.

**Status:** planning — see [docs/ROADMAP.md](docs/ROADMAP.md). Agent rules: [AGENTS.md](AGENTS.md).

Stack: .NET 10 · ASP.NET Core · EF Core · PostgreSQL · Nuxt 4 · TypeScript · Claude API · Docker · GitHub Actions (Azure later).
